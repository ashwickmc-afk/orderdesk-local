# Historical OrderDesk releases

The repository includes source snapshots and descriptions of the earlier iterations. Historical versions are not maintained; use `apps/local` for the recommended current edition or `apps/cloud` for the optional Cloud beta.

| Version | What it represents | Repository snapshot |
|---|---|---|
| v0.1.0 | First local order dashboard prototype | [HTML source](releases/v0.1.0/index.html) |
| v0.2.0 | Readability, dark mode, customer summaries and payment improvements | [HTML source](releases/v0.2.0/index.html) |
| v0.3.0 | Installable PWA with responsive layout, manifest and offline app shell | [Preview HTML](releases/v0.3.0/orderdesk_v0_3_preview.html) and [notes](releases/v0.3.0/README.md) |
| v0.4.0 | First Supabase login and cloud-sync experiment | [Release notes](releases/v0.4.0/README.md) |
| v0.4.1 | Login and asset-path repair for the v0.4 experiment | [Release notes](releases/v0.4.1/README.md) |
| v0.5.0 | Local Business Edition with no login/backend, Money Book and calculators | [HTML source](releases/v0.5.0/index.html) |

The original v0.3.0, v0.4.0 and v0.4.1 ZIP packages were retained in the earlier development archive, but are not currently part of this GitHub source tree. Their features and limitations are described above and in [CHANGELOG.md](../CHANGELOG.md).
