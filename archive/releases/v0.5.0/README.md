# OrderDesk v0.5.0 — Local Business Edition

The v0.5 pivot removed Supabase, login, customer accounts and cloud sync. It focused on the business owner and introduced the Money Book, profit calculator, quick calculator and payment follow-up alongside order/customer management, local backups and CSV exports.

The preserved `index.html` is the original v0.5 source. The current no-login version is `apps/local` (v0.6.0) and keeps the same IndexedDB database name to preserve v0.5 records in the same browser profile.
