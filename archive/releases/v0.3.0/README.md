# OrderDesk v0.3.0 — Installable PWA

This milestone converted the order manager into a responsive Progressive Web App for desktop, laptops, tablets and phones. It added the PWA manifest, offline app-shell caching, install guidance and app icons. WhatsApp drafts no longer exposed the internal order reference in customer-facing text.

The original ZIP package is not stored in this repository. This folder contains the preserved v0.3 preview HTML; current maintained PWA code is in `apps/local`.
