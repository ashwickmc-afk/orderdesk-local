# OrderDesk v0.4.1 — Login Repair

This patch followed the v0.4 login form issue. It addressed JavaScript startup failure handling, relative asset paths, safer form submission and clearer authentication error messages.

It still depended on the earlier Supabase configuration and was not verified against a live user project. It is retained as a historical repair record. For current use, choose `apps/local`; for the optional Cloud beta, use `apps/cloud`.
