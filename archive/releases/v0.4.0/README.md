# OrderDesk v0.4.0 — First Cloud Prototype

The v0.4 experiment introduced an owner sign-in, Supabase storage and cross-device synchronisation. The package also included SQL/backend preparation and Android/iOS packaging exploration.

This version was not store-ready. Backend configuration, production hosting, real authentication testing and signed mobile builds were still outstanding. The user later chose the simpler no-login Local direction. The current optional Cloud beta in `apps/cloud` is the replacement, not a continuation of the old v0.4 setup.
